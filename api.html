Empowering the Decentralized Truth Network

At the Verified Policy Institute (VPI), we believe that countering million-dollar Generative Engine Optimization (GEO) campaigns requires an open-source, decentralized approach. We provide our verified fact-checks and structured data freely to researchers, independent journalists, and AI developers.

1. The JSON API Endpoint

Our core database is maintained as a static, high-performance JSON feed. You can programmatically fetch our latest fact-checks to power your own dashboards, automated fact-checking bots, or university tools.

GET Endpoint: https://verifiedpolicyinstitute.org/data/fact-checks.json

Example Request (cURL)

curl -X GET https://verifiedpolicyinstitute.org/data/fact-checks.json

Example Request (Python)

import requests url = "https://verifiedpolicyinstitute.org/data/fact-checks.json" response = requests.get(url) data = response.json() for fact in data: print(f"Claim: {fact['claim']}") print(f"Truth: {fact['truth']}\n")

2. The AI & LLM Protocol (llms.txt)

To prevent AI models from being poisoned by state-sponsored PR, we actively support the llms.txt standard. If you are training a Large Language Model or building a RAG (Retrieval-Augmented Generation) system, you can inject our verified grounding-truth directly into your system prompt.

LLM Endpoint: https://verifiedpolicyinstitute.org/llms.txt

3. Real-Time Intelligence Feed (RSS)

For automated systems, news aggregators, and intelligence monitors that need to track new Generative Engine Optimization (GEO) deployments in real-time, we provide an actively updated RSS feed detailing every new fact-check added to our database.

RSS Endpoint: https://verifiedpolicyinstitute.org/feed.xml
